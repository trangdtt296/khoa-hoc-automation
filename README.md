# Lộ trình tự học Automation Tester

Khoá tự học dành cho tester thủ công muốn chuyển sang automation, viết cho người **chưa biết lập trình**.

Biên soạn: **TrangDTT59**

## Mở khoá học

👉 **https://trangdtt296.github.io/khoa-hoc-automation/**

Toàn bộ nội dung nằm trong một trang web tĩnh, không cần cài gì, mở bằng trình duyệt là học được. Trang tự ghi nhớ bài bạn đã học trên chính trình duyệt đó.

## Cấu trúc mỗi bài

- **Mục tiêu** — học xong bài này làm được gì
- **Lý thuyết ngắn** — giải thích mọi thuật ngữ tiếng Anh ngay lần đầu xuất hiện
- **Code mẫu** — copy chạy được ngay
- **Bảng tổng hợp** — tra nhanh khi quên
- **Lỗi hay gặp** — thông báo lỗi thật kèm cách sửa
- **Bài tập** — tự làm để nhớ

Mỗi bài khoảng 1–2 giờ.

## Nên bắt đầu từ đâu

Chưa biết lập trình, muốn test web → **Khoá Playwright**, bắt đầu từ Bài 0.

Chưa biết lập trình, muốn test app điện thoại → **Khoá Maestro**, viết bằng YAML nên không cần code.

Đã biết chút lập trình, muốn khớp JD tuyển dụng → **Khoá Appium + Java**.
